# TechLexicon

For Persian speakers who want to learn IT terms in German — especially those planning to work or study in German-speaking countries.

German-English-Persian IT glossary.

## Technologies

- Python
- Pelican (Static Site Generator)
- Markdown
- Bootstrap 4
- GitHub Pages

## Setup

```bash
git clone <repo>
cd TechLexicon
python -m venv venv
source venv/bin/activate
pip install pelican[markdown]
pelican -lr
```
